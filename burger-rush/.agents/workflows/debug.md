# Debug

## Objetivo

Investigar e corrigir problemas técnicos no projeto BurguerRush.

## Processo

1. Reproduzir ou compreender o problema.
2. Identificar o sistema responsável.
3. Inspecionar logs, erros e código relacionado.
4. Determinar a causa raiz antes de modificar o código.
5. Implementar a menor correção adequada.
6. Validar que o problema foi corrigido.
7. Verificar possíveis efeitos colaterais.

## Regras

* Não mascarar erros apenas removendo mensagens ou desativando sistemas.
* Não reescrever sistemas inteiros sem necessidade.
* Corrigir a causa do problema sempre que possível.
* Preservar o comportamento que já funciona.
* Se a causa não puder ser determinada com segurança, informar o que foi encontrado antes de realizar alterações arriscadas.

## Resultado esperado

Informar:

* problema identificado;
* causa provável ou confirmada;
* correção realizada;
* arquivos modificados;
* validações realizadas.
