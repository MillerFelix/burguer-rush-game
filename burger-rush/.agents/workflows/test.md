# Test

## Objetivo

Validar uma implementação ou investigar se uma funcionalidade do BurguerRush está funcionando corretamente.

## Processo

1. Identificar o comportamento esperado.
2. Inspecionar a implementação relevante.
3. Executar testes automatizados quando existirem.
4. Executar validações específicas da Godot quando possível.
5. Procurar erros de sintaxe, referências quebradas e problemas de integração.
6. Informar claramente o que foi validado.

## Regras

* Não modificar código durante este workflow, exceto quando o criador solicitar explicitamente correção.
* Não considerar uma funcionalidade correta apenas porque o código parece correto.
* Diferenciar claramente entre testes realizados e testes que não puderam ser realizados.

## Resultado esperado

Informar:

* testes executados;
* resultado;
* problemas encontrados;
* limitações da validação.
